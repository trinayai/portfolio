# Fix "Page Not Found" Deployment Error

We will resolve the 404/Not Found issue in the deployed domain by aligning the build output directory and ensuring the entry point for App Hosting is correctly identified.

## Proposed Changes

### 1. Update App Hosting Configuration
We will add explicit build configurations to `apphosting.yaml` to ensure Firebase knows exactly where the built files are.

#### [MODIFY] [trinayai-web/apphosting.yaml](file:///F:/Trinay-AI/Home/Web_app/trinayai-web/apphosting.yaml)
- Add `buildConfig`:
    - `buildCommand: npm run build`
    - `outputDirectory: dist/trinayai-web` (The parent of browser/server folders)

#### [MODIFY] [trinayai-admin/apphosting.yaml](file:///F:/Trinay-AI/Home/Web_app/trinayai-admin/apphosting.yaml)
- Add `buildConfig`:

### 2. Standard Hosting Fallback (Optional but Recommended)

### 3. Align Application Versions
We will ensure both applications use the same Angular and Node.js versions to prevent deployment and runtime inconsistencies.
- **Angular**: Align both `trinayai-web` and `trinayai-admin` to **17.3.12**.
- **Node.js**: Set `engines.node` to **20** in all `package.json` files.
- **PrimeNG**: Align to **17.18.15** (matching the working main app state).

### 4. Synchronize Dependencies
Ensure `package-lock.json` is perfectly in sync with `package.json` to prevent `npm ci` failures.
- Run `npm install --package-lock-only --legacy-peer-deps` in all module directories.

### 5. Re-deploy
- Run `firebase deploy --project trinay-ai`.
